# Agent Guide

This project was generated by Crank.

The project root contains `.crank.yaml`. Use it as the source of truth for enabled Crank features.

## Crank CLI

Use the system-installed `crank` CLI for common project tasks. Do not use `./crank`.

```bash
crank run              # start the dev server
crank build            # build the project
crank test             # run tests
crank gofmt            # format Go code
crank vet              # run Go vet
crank tidy             # tidy Go modules
crank swag             # generate Swagger docs
crank migrate up       # run database migrations
crank seed up          # run database seeds
crank seed generate    # generate seed files
```

If running commands from outside the project root, pass `--project`:

```bash
crank test --project /path/to/project
```

If `.crank.yaml` is missing, do not assume the repository is managed by Crank.

## Enabled Features

Always verify against `.crank.yaml`. Do not assume a feature is present — check the manifest first.

Common features: `base` (always), `gorm`, `auth`, `redis`, `mongodb`, `qdrant`, `temporal`, `otel`, `outbox`, `crypto`, `audit`, `views`.

## Code Generation

Prefer Crank generators over hand-writing boilerplate:

```bash
crank make model Order customer:string total:float
crank make handler Product title:string price:float
crank make scaffold Invoice number:string amount:float
crank make migration create_orders
crank seed generate Order --count 20
```

For Temporal projects: `crank make workflow` / `crank make activity`.

## Frontend (`views` feature only)

When `views` is enabled, a React + Vite SPA lives under `views/` and is served embedded from the Go binary in production.

```bash
cd views && npm install     # one-time setup
cd views && npm run dev     # Vite HMR on :5173 (proxies /api to :8080)
cd views && npm run build   # emits static/dist/, then run `crank build` to embed
```

Set `views.dev_server: "http://localhost:5173"` in config for HMR; leave empty to serve the embedded bundle.

## Adding Features

```bash
crank add redis
crank add temporal
crank add views
```

Crank uses marker-based injection to preserve user edits when adding features.
